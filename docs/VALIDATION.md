# 验证记录

验证环境：Linux x86_64，Python 3.12.14，torch 2.9.0+cpu，torchvision 0.24.0+cpu，Ultralytics 8.3.228，OpenCV 4.12.0.88，NumPy 2.2.6，lap 0.5.12。测试使用 CPU。

## 自动测试

`python -m pytest -q`：21 个测试通过，覆盖：

- 有限线段相交与延长线排除。
- 进口→出口配对、单 ID 单线去重，以及同一帧跨越多条线时按事件时间排序。
- 计数线附近抖动、遮挡间隙、过期轨迹清理。
- 越线方向和类别筛选。
- OpenCV 解码、CSV 写入、分箱和零计数。
- 完成文件跳过、配置变化拒绝覆盖、中断目录保留、试运行时长限制。
- 离线标注页面生成与汇总导出。
- 本地 CUDA wheel 选择、旧驱动拒绝、旧显卡架构选择、含空格路径的启动参数、VS Code 虚拟环境配置与失败后旧成功状态失效。
- 中文场景名称与 UTF-8 元数据恢复，避免依赖 Windows 的默认文本编码。

CLI 集成测试使用真实 OpenCV 编码/解码和确定性检测替身，验证统计逻辑，避免把模型识别波动当作计数逻辑测试结果。`python -m pip check` 未发现依赖冲突。
